# T1 第四组：稳态导热参数敏感性实验台

第四组围绕“一维平壁稳态导热”的参数敏感性视角制作的交互作品。

## 在线访问

<https://stormbobtang29-cyber.github.io/t1-heat-transfer-group4/>

## 主要功能

- S1 无内热源与 S2 均匀内热源解析模型
- 参数调整与温度分布实时联动
- 热流密度、传热量、Bi 数与能量闭合
- 标准化局部灵敏度与单因素参数扫描
- CSV 实验数据导出
- 8 项自动物理校验
- 一页 A4 参数敏感性报告打印

## 文件

- `index.html`：完整实验台，单文件离线运行。
- `favicon.svg`：网页标签图标。
- `.nojekyll`：要求 GitHub Pages 直接发布静态文件。
