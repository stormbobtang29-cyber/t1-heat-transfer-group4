# 第四组 T1 稳态导热 GitHub Pages 上传包

本目录只包含公开网页所需文件：

- `index.html`：网站入口，打开链接后直接显示实验台。
- `favicon.svg`：浏览器标签图标。
- `.nojekyll`：要求 GitHub Pages 直接发布静态文件。

## 推荐发布方法

1. 在 GitHub 新建一个公开仓库，建议名称：`t1-heat-transfer-group4`。
2. 进入仓库，选择 **Add file → Upload files**。
3. 把本目录中的三个文件一起上传并提交。
4. 打开仓库 **Settings → Pages**。
5. 在 **Build and deployment** 中选择 **Deploy from a branch**。
6. Branch 选择 `main`，文件夹选择 `/(root)`，然后保存。
7. 等待部署完成，页面地址通常为：

   `https://你的GitHub用户名.github.io/t1-heat-transfer-group4/`

GitHub 官方提示首次发布或更新可能需要约 10 分钟。

## 公开前检查

- 不要在网页中填写学号、手机号等不需要公开的信息。
- 若填写组员姓名，请先取得组员同意。
- 正式提交前，把教师锁定参数和物性来源更新到网页中。
- 仓库设为公开时，其中的源文件也会公开。

## 发给老师时

网页链接用于交互演示；同时建议另发一页 A4 PDF、物理设定表和每位成员自己的 AI 质疑记录，避免只发链接而漏交任务单规定材料。
